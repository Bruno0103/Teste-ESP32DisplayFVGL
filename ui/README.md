# 🎨 Módulo de Interface Gráfica (UI LVGL)

Este módulo é gerenciado pelo **`lvgl-ui-doc-agent`**.

---

## 📂 Estrutura de Arquivos

- **`screens/`**: Contém as telas geradas (`preview_home_gen.c`, `screen1_gen.c`).
- **`components/`**: Componentes gráficos modulares (`battery_body`, `infobar`, barras, contêineres).
- **`fonts/`**: Matrizes de fontes C estáticas.
- **`images/`**: Matrizes de dados de imagens C (ícones RGB).
- **`ui_gen.h` / `ui_gen.c`**: Definições globais de estilos e observadores `lv_subject_t`.
- **`ui.h` / `ui.c`**: Ponto de inicialização `ui_init()`.
